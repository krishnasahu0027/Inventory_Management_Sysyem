# Inventory_Management_Sysyem

**Yuva Intern — Junior Java Developer, Week 1**

## Files
- `Index.html` — page structure and product form
- `Styles.css` — responsive dashboard styling
- `Data.js` — sample inventory products
- `app.js` — search, add/edit/delete, validation, calculations, and localStorage
- `Manifest.json` — basic web-app metadata
- `Readme.md` — setup and project notes

## Features
- Dashboard summary: products, units, inventory value, and low-stock count
- Search products by name, SKU, or category
- Add, edit, and delete products
- Duplicate SKU validation
- Low-stock warnings based on reorder level
- Indian Rupee formatting
- Saves changes in the current browser
